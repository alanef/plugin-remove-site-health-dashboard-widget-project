# Release 1.2.0

**Date:** 2026-10-23
**Previous:** 1.1.2

## Highlights
The opt-in notice can be dismissed, "Allow & Continue" subscribes you again, and deleting the plugin cleans up
after itself. The PHP minimum rises to 7.4, which the bundled library has needed all along.

## What's New
### Features
- FAQ entry on reporting security bugs through the Patchstack Vulnerability Disclosure Program (12209b7, no ticket)

### Fixes
- The opt-in notice could not be dismissed and came back on every page load
- "Allow & Continue" subscribed nobody and recorded the user as opted out (PLUGINS_SMALL-7)
- On sites running other Fullworks free plugins, the notice could belong to the wrong plugin
- Deleting the plugin now removes its opt-in setting (new uninstall.php)

### Improvements
- The notice links to the opt-in screen, with accurate wording
- Bundled opt-in library 1.0.1 -> 1.3.3
- Tested up to WordPress 7.1 (174c390, no ticket)

## Breaking Changes
Requires PHP 7.4 (was 5.6). WordPress.org stops offering the update to sites on older PHP. Those sites could not
run the bundled library's opt-in anyway.

## Migration Guide
None. Stored choices are kept, and users silently recorded as opted out are not asked again (Alan's decision).
